# BrewLite

Ứng dụng đặt cà phê không dùng tiền mặt (Bài tập lớn môn Công nghệ Phần mềm, Đại học Sài Gòn).

## Công nghệ
- Frontend: Next.js (React, TypeScript), TailwindCSS
- Backend: NestJS (TypeScript)
- CSDL: PostgreSQL + Prisma
- Triển khai: Docker Compose

## Yêu cầu cài đặt
Node.js LTS, Git, Docker Desktop.

## Chạy môi trường dev
1. Backend:
   cd backend
   cp .env.example .env
   npm install
   npm run start:dev   (chạy tại http://localhost:3001)
2. Frontend:
   cd frontend
   cp .env.example .env.local
   npm install
   npm run dev   (chạy tại http://localhost:3000)
